### Описание процесса тестирования ПО УФ пеленгатора

#### **1. Общая структура проекта**
Проект состоит из нескольких ключевых файлов, каждый из которых выполняет свою функцию:

1. **`simulator_py.py`**  
   - Имитирует работу УФ пеленгатора через JSON-RPC API.
   - Запускает HTTP-сервер на порту `8080`.
   - Поддерживает методы:
     - `VideoRpc.Status` — запрос статуса (`idle`, `show`, `record`).
     - `VideoRpc.Show` — запуск трансляции.
     - `VideoRpc.Stop` — остановка активности.
     - `VideoRpc.Record` — запуск записи.
   - Генерирует имитацию УФ-излучения (синие точки на черном фоне).

2. **`client_script.py`**  
   - Клиент для ручного тестирования API симулятора.
   - Позволяет отправлять команды и проверять ответы в консоли.

3. **`integration_module.py`**  
   - Модуль интеграции между GUI и симулятором.
   - Реализует фоновый мониторинг статуса устройства.
   - Предоставляет методы для управления устройством (`start_streaming`, `stop`, `start_recording`).

4. **`complete-web-interface.html`**  
   - Веб-интерфейс для управления симулятором.
   - Отображает статус устройства, имитацию УФ-излучения и журнал событий.
   - Взаимодействует с симулятором через JSON-RPC.

5. **`auto_test_script.py`**  
   - Автоматизированные тесты взаимодействия GUI и симулятора.
   - Использует Selenium для проверки веб-интерфейса.

6. **`integration-test-script.py`**  
   - Основной скрипт для запуска всей системы.
   - Управляет симулятором, веб-сервером и клиентом.

---

#### **2. Пошаговый ход тестирования**

### **Шаг 1: Запуск симулятора**
**Файл:** `simulator_py.py`  
**Команда:**  
```bash
python simulator_py.py
```
**Что делает:**  
- Запускает сервер на `localhost:8080`.  
- Готов принимать JSON-RPC запросы от GUI или тестовых скриптов.  

**Проверка работы:**  
Отправляем запрос вручную через `curl`:  
```bash
curl -X POST http://localhost:8080/jsonrpc -H "Content-Type: application/json" -d '{"jsonrpc":"2.0","method":"VideoRpc.Status","id":1}'
```
Ожидаемый ответ:  
```json
{"jsonrpc": "2.0", "result": {"res": "idle"}, "id": 1}
```

---

### **Шаг 2: Тестирование API симулятора**
**Файл:** `client_script.py`  
**Команда:**  
```bash
python client_script.py
```
**Что делает:**  
- Последовательно отправляет команды:
  1. Получает статус (`VideoRpc.Status`).
  2. Запускает трансляцию (`VideoRpc.Show`).
  3. Останавливает трансляцию (`VideoRpc.Stop`).
  4. Запускает запись (`VideoRpc.Record`).
  5. Останавливает запись (`VideoRpc.Stop`).

**Пример вывода:**  
```
Текущий статус: idle
Запуск трансляции...
Статус после запуска трансляции: show
Остановка трансляции...
Статус после остановки трансляции: idle
```

---

### **Шаг 3: Запуск веб-интерфейса**
**Файл:** `complete-web-interface.html`  
**Способ запуска:**  
Через `integration-test-script.py` (автоматически запускает веб-сервер).  

**Команда:**  
```bash
python integration-test-script.py
```
**Что делает:**  
1. Запускает симулятор (`simulator_py.py`).  
2. Запускает веб-сервер на `localhost:3000`.  
3. Открывает браузер с интерфейсом управления.  

**Интерфейс включает:**  
- Кнопки управления (`Запустить трансляцию`, `Запустить запись`, `Остановить`).  
- Имитацию УФ-излучения (синие точки).  
- Журнал событий.  

---

### **Шаг 4: Автоматизированное тестирование**
**Файл:** `auto_test_script.py`  
**Команда:**  
```bash
python auto_test_script.py
```
**Что проверяет:**  
1. Начальное состояние симулятора (`idle`).  
2. Запуск и остановку трансляции.  
3. Запуск и остановку записи.  
4. Обработку некорректных команд.  

**Пример вывода:**  
```
Тест 1: Проверка начального состояния симулятора
✓ Начальное состояние симулятора: idle
Тест 2: Запуск трансляции
✓ Состояние после запуска трансляции: show
```

---

### **Шаг 5: Интеграция GUI и симулятора**
**Файл:** `integration_module.py`  
**Как используется:**  
- Веб-интерфейс (`complete-web-interface.html`) вызывает методы из `UVDetectorIntegration`.  
- Пример работы:  
  ```javascript
  // В веб-интерфейсе
  async function startStreaming() {
      const response = await fetch('http://localhost:8080/jsonrpc', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({
              jsonrpc: '2.0',
              method: 'VideoRpc.Show',
              id: Date.now()
          })
      });
      const data = await response.json();
      if (data.result) {
          console.log("Трансляция запущена");
      }
  }
  ```

#### **4. Как запустить процесс тестиованиея**
1. **Архив проекта:**  
   - Распакуйте все файлы из ZIP:  
     ```
     simulator_py.py
     client_script.py
     integration_module.py
     complete-web-interface.html
     auto_test_script.py
     integration-test-script.py
     README.md (описание запуска)
     ```

2. **Инструкция в README.md:**  
   ```markdown
   # Тестирование ПО УФ пеленгатора

   ## Запуск системы
   1. Установите зависимости:
      ```bash
      pip install requests selenium opencv-python
      ```

   2. Запустите симулятор:
      ```bash
      python simulator_py.py
      ```

   3. Запустите веб-интерфейс:
      ```bash
      python integration-test-script.py
      ```

   4. Для тестирования API используйте:
      ```bash
      python client_script.py
      ```

   5. Для запуска автотестов:
      ```bash
      python auto_test_script.py
      ```

   ## Описание компонентов
   - `simulator_py.py` — имитация устройства.
   - `complete-web-interface.html` — GUI для управления.
   - `integration-test-script.py` — основной скрипт интеграции.
   ```

---

#### **5. Демонстрация работы**
1. Запустите `integration-test-script.py`.  
2. Откройте `http://localhost:3000/web_interface.html`.  
3. Нажмите кнопки в интерфейсе и убедитесь, что:  
   - Статус меняется (`idle` → `show` → `record`).  
   - В журнале появляются записи.  
   - На "экране" отображаются синие точки (имитация УФ-излучения).  

4. Для проверки автотестов запустите `auto_test_script.py` и убедитесь, что все тесты проходят.
